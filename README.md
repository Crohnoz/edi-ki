# Edi Ki Acción

Propuesta **pro bono** de [Crohnoz Impact](https://github.com/Crohnoz) para apoyar la organización de iniciativas comunitarias impulsadas por Edi Ki.

## Objetivo

Convertir el alcance de sus redes sociales en una plataforma sencilla para:

- publicar convocatorias comunitarias;
- registrar voluntarios;
- informar materiales y herramientas requeridas;
- recibir ofrecimientos de apoyo;
- mostrar resultados y evidencias;
- coordinar actividades con autorizaciones y protocolos de seguridad.

## Estado

Prototipo conceptual. Las fechas, métricas, fotografías y actividades incluidas en la demo deben validarse directamente con Edi Ki antes de su publicación oficial.

## Ejecutar localmente

No requiere instalación:

```bash
python -m http.server 8000
```

Luego abre `http://localhost:8000`.

## Principios

- Sin cobro ni comisión para la iniciativa.
- Administración y datos bajo control del responsable del proyecto.
- Privacidad por diseño y recopilación mínima de datos.
- Convocatorias publicadas únicamente con autorización del lugar correspondiente.
- Seguridad y prevención de riesgos como requisitos operativos.
